# 手机浏览器使用说明

手机和电脑使用同一个 `index.html`，无需安装应用或构建。建议由静态网站提供 HTTPS 地址，在手机浏览器访问。也可尝试下载 HTML 后选择浏览器打开；部分手机文件管理器的 HTML 预览不会执行脚本，这时应通过网站访问。

## 排行操作

1. 点击“添加图片”，从相册或文件中选择图片，可多选。
2. 滑动卡片封面可以滚动页面。轻点封面，选择要移动到的档位；卡片会追加到目标末尾。
3. 也可以按住封面左上角的拖动手柄，移至目标位置后松手。在页面顶端或底端停留会自动滚屏。
4. 同档位排序既可拖动，也可点封面后使用“向前一位 / 向后一位”。名称仍可直接点按编辑。
5. 卡片菜单提供放回素材池和删除。模板、增删档位、配色和 JSON 导入导出继续可用。

## 保存图片和存档

“导出图片”生成 PNG 预览。可长按图片保存，或点击“下载 PNG”。浏览器支持文件分享时，会出现“系统分享”按钮；此功能通常需要 HTTPS 和用户点按。取消系统分享不会删除榜单。

PNG 保持原来的每行最多 12 张、封面无间隙布局，素材池不参与导出。导出尺寸独立于手机屏幕尺寸。特别长的榜单仍可能超过手机内存或画布上限。

请用“导出”保存 JSON 备份，也可将电脑上的 JSON 传到手机后“导入”继续编辑。自动保存只属于当前浏览器和访问地址，不会自动在电脑和手机之间同步。换地址、换浏览器或清理站点数据前先备份。

## 验证边界

自动化验证使用 Windows 上的无头 Chromium，模拟手机尺寸和触摸输入。Android Chrome、iOS Safari、相册保存和系统分享仍需手机真机验收；不能把模拟结果当成真机验证。
