# v0.2.0 · 手机浏览器适配

本次更新让手机和电脑共用同一份排行榜网页，主要改善手机上的滚动、卡片整理和图片保存。

## 下载使用

- `custom-tier-list-maker-v0.2.0.zip`：完整便携包，含网页入口、示例、说明和验证脚本，解压后打开 `index.html`。
- `custom-tier-list-maker.html`：单文件版，用浏览器打开即可。
- `SHA256SUMS.txt`：上述两个文件的 SHA256 校验值。

手机建议通过 HTTPS 静态网站访问。仓库目前未启用在线托管；本次发布提供下载文件。部分手机文件管理器的 HTML 预览不会执行脚本，此时需选择浏览器打开，或自行部署到静态网站。

## 手机端有什么变化

1. **封面滑动滚屏，手柄拖动排序。** 滑动封面不会再被卡片拖拽拦住；按住左上角手柄即可拖动，在页面上、下边缘停留会自动滚屏。
2. **轻点封面就能移档。** 菜单可将卡片移至任意档位末尾、放回素材池、前后移动或删除，适合不方便跨屏拖拽的长榜单。点名称仍可编辑。
3. **手机布局与触控按钮。** 工具栏保留文字，窄屏下工具栏和卡片自动三列排列，扩大档位操作和调色板按钮，弹窗适配屏幕高度及安全区。
4. **PNG 预览与保存。** 手机导出后显示图片预览，可长按保存或下载。浏览器支持系统文件分享时，提供“系统分享”按钮。

同时修复图片上传区域内文件输入点击重复触发的问题。桌面鼠标拖拽、每行最多 12 张的无间隙 PNG 布局、JSON 存档格式和浏览器存储键继续保留。

## 升级与数据

升级前请先导出 JSON 备份。更换 HTML 路径、浏览器或访问地址后，原来的自动保存可能不再可见，可导入 JSON 恢复。电脑与手机之间不会自动同步；PNG 仅包含分级区，素材池不进入导出图片。

发布包使用通用演示素材，不包含个人榜单、封面或浏览器存储。

## 验证范围

已通过 31 项 Windows 无头 Chromium 自动检查，包括多种手机尺寸和横屏、触摸滑动、手柄拖拽、移档排序、边缘自动滚屏、取消拖拽、旧 JSON 导入、刷新恢复、本地图片上传、PNG 预览及实际下载、桌面鼠标拖拽。已查看手机布局截图。

这些结果属于浏览器模拟验证。Android Chrome、iOS Safari 真机、相册保存和系统分享弹窗仍待验收；极长榜单仍可能受到手机内存和浏览器画布上限限制。
