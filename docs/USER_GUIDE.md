# 使用说明

## 创建与整理

打开 `index.html`。初始素材池有 8 张通用演示卡片，可删除或直接用于试用。清空会恢复默认档位与演示卡片。

点击顶部标题修改榜单名称。点击档位文字改名，回车可换行；颜色按钮打开调色板。新增档位可继续添加分类，删除档位会将其中卡片退回素材池。

“添加图片”支持多选本地图片或填写外部图片链接。为了离线可用及稳定导出，优先上传本地图片。图片加入后点击卡片文字可编辑，回车结束。

按住卡片拖到目标档位，可以调整档内先后顺序，也可以移回素材池。触屏使用长按后拖动，实际体验取决于浏览器与设备。卡片单击操作会提供返回素材池等菜单，素材池卡片的删除按钮会移除条目。

## 保存与复用

“导出”保存 JSON 完整存档，是保留可编辑内容的主要方式。“导入”载入 JSON，当前已有内容时会提示覆盖，请先备份。这里只接受工具自身或兼容格式的 JSON，不接受 Excel。

“模板”中“保存模板”只保存标题、档位文字及颜色，不保存图片卡片。载入结构模板会清空当前图片，请留意确认提示。“保存当前演示”按钮执行图片导出，并不是额外的完整存档功能。

## 图片导出

“导出图片”输出 PNG，只有放进档位的卡片会显示。素材池中的卡片不会显示。每行最多 12 张，封面以 2:3 居中裁切，相邻图片无间隙。长名称最多显示两行，可简化显示文字并另留 JSON 完整存档。

若外站图片加载失败或禁止跨域读取，导出会用名称占位。可改为先获得有权使用的本地图片，再上传添加。

## 常见问题

- **换浏览器后榜单不见了：** 自动保存不跨浏览器同步，导入之前导出的 JSON 即可恢复。
- **PNG 中没有素材：** 确认卡片已拖进上方档位，素材池不参与 PNG 导出。
- **图片名称不完整：** 批量上传的默认名称会截短，可直接点击文字补全。
- **清空后还有卡片：** 清空恢复默认演示状态，不是完全空白。需要空白可导入 `examples/通用空白模板.json`。
- **离线打开：** 使用本地图片和内置演示图即可离线运行，外站图片链接需要网络。
- **本地打开存档异常：** file:// 下持久化行为因浏览器而异，可换现代桌面浏览器，或从固定静态站点访问，并主动导出 JSON 备份。
